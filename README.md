# Kecanduan HP? It's Red Red!

Website edukasi responsif tentang kebiasaan penggunaan HP, dibuat dengan HTML, CSS, dan JavaScript murni.

## Isi folder
- `index.html` — struktur halaman dan materi edukasi.
- `style.css` — desain website dan tampilan responsif untuk HP/laptop.
- `script.js` — navigasi menu dan mini game Good Choice vs Bad Choice (5 situasi, feedback, animasi, skor, hasil, dan tombol main lagi).

## Melihat website di komputer
1. Ekstrak file ZIP.
2. Buka folder `kecanduan-hp-website`.
3. Klik dua kali `index.html` untuk membukanya di browser.

## Upload ke GitHub Pages
1. Login ke https://github.com
2. Klik **New repository**. Isi nama `kecanduan-hp`, pilih **Public**, lalu klik **Create repository**.
3. Di repository baru, klik **Add file → Upload files**.
4. Upload `index.html`, `style.css`, dan `script.js` dari folder ini. (README boleh ikut.)
5. Klik **Commit changes**.
6. Buka **Settings → Pages**.
7. Pada **Build and deployment**, pilih **Deploy from a branch**.
8. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
9. Setelah proses publikasi selesai, alamat situs biasanya `https://USERNAME.github.io/kecanduan-hp/` (ganti USERNAME dengan username GitHub kamu).

## Mengganti visual menggunakan Canva
Buat atau ekspor ilustrasi/banner dari Canva sebagai PNG/JPG. Buat folder bernama `assets` di repository, upload gambar, lalu kita bisa memasukkan gambar tersebut ke website. Desain yang ada sekarang adalah desain awal dan masih bisa disesuaikan dengan hasil Canva kamu.

Catatan: website ini merupakan materi edukasi dan refleksi kebiasaan, bukan alat diagnosis medis. Font Google hanya akan dimuat jika perangkat terhubung ke internet; jika tidak, browser memakai font pengganti.
